## Technology Intelligence
_ref: `docs/Ontology/Technology.md`_

System Architecture: PPoS dengan cryptographic sortition — validator dipilih acak berbobot stake per blok; finalitas <5 detik; tanpa forking; throughput >1,000-10,000 TPS klaim.
Core Components: Relay & participation nodes, AVM (smart contracts TEAL/PyTeal), ASA (token standar), state proofs (bridging), xGov/governance platform.
Consensus Mechanism: Pure Proof-of-Stake (aBFT praktis via sortition).
Security Model: Keamanan = distribusi stake; resistensi fork; energi rendah; risiko: konsentrasi stake awal di foundation/grants.
Technical Upgrade History: Mainnet 2019 → ASA → smart contracts → state proofs → governance program 2021 → staking rewards 2025.
Known Technical Limitations: Ekosistem DeFi lebih kecil dibanding L1 besar; adopsi developer terbatas relatif; sentralisasi persepsi awal (foundation memegang alokasi besar).

## Behavioral Intelligence
_ref: `docs/Ontology/Hidden.md` — enriches DecisionEvent Alternatives/Reason/Reactions_

Strategic Objectives

1. Mencapai finalitas & throughput tinggi tanpa mengorbankan desentralisasi (PPoS)
Sortition acak berbobot stake memberi finalitas instan; desain akademis-first.
Evidence: Whitepaper 2017 & klaim protokol (HIGH) [Grokipedia]

2. Distribusi token via auction + grants untuk bootstrap infrastruktur tanpa ICO spekulatif
Dutch auction menurunkan harga bertahap; node grants mengamankan relay nodes awal.
Evidence: 99bitcoins; Medium/PowerTrade (MEDIUM)

3. Transisi insentif: participation → governance → staking rewards
Setiap era menyesuaikan tujuan: adopsi holder → keterlibatan voting → keamanan jaringan.
Evidence: 99bitcoins-staking; Ledger; Algodaddy (MEDIUM)

Technical Decision Pattern

Pola 1: Consensus akademis-first (PPoS) sebagai diferensiasi vs Nakamoto/PoS konvensional
Kekuatan: finalitas & energi; kelemahan: persepsi & adopsi lebih lambat dari chain EVM populer.
Evidence: EV-001; Grokipedia (HIGH)

Pola 2: State proofs untuk interoperabilitas ringan tanpa bridge terpercaya
Teknik verifikasi lintas-chain berbasis proof konsensus.
Evidence: Grokipedia (MEDIUM)

Financial Decision Pattern

Pola 1: Dutch auction bertahap sebagai mekanisme price-discovery "adil"
Menurunkan harga dari titik awal sampai terserap — kontras ICO harga tetap.
Evidence: EV-003 (MEDIUM)

Pola 2: Yayasan memegang tranche besar + vesting panjang (~2030)
Menjamin pendanaan ekosistem jangka panjang; biaya: kritik sentralisasi.
Evidence: Medium/PowerTrade; Grokipedia (MEDIUM)

Governance Decision Pattern

Pola 1: Rewarded governance (commit+voting) lalu pengakhiran rewards 2024-2025
Governance berinsentif menaikkan partisipasi; setelah tujuan tercapai, voting jadi sukarela.
Evidence: Algodaddy; 99bitcoins-staking (MEDIUM)

Risk Response Pattern

Pola 1: Mengganti skema insentif bila tujuan bergeser (partisipasi→voting→keamanan)
Adaptif lintas siklus tanpa mengubah konsensus inti.
Evidence: EV-004..EV-007 (MEDIUM)

Recurring Behavioral Pattern

Pola 1: Distribusi terpusat-foundation dengan pelepasan bertahap
Kontras fair-launch; menciptakan tekanan jual terjadwal namun pendanaan ekosistem stabil.
Evidence: Distribution table (MEDIUM)

Strategic Trade-offs

Trade-off 1: Kecepatan/finalitas vs adopsi ekosistem
PPoS unggul teknis; ekosistem DeFi kalah network-effect dari EVM L1 besar.

Trade-off 2: Foundation-heavy distribution vs persepsi desentralisasi
Alokasi besar foundation/grants membiayai dekade pengembangan; biaya narasi sentralisasi.

Trade-off 3: Governance rewards (likuiditas terkunci) vs kebebasan holder
Commit kuartalan menaikkan keterlibatan; sebagian holder memilih keluar dari program.

Decision Event: 2021-10-01 — Mengganti participation rewards pasif dengan governance rewards

Motivation: Reward pasif tidak menciptakan keterlibatan & tidak mendukung desentralisasi keputusan; holder menerima ~7.5% tanpa komitmen. (MEDIUM) [99bitcoins-staking, https://99bitcoins.com/cryptocurrency/best-crypto-staking-coins/algorand/]

Constraint: Tekanan komunitas atas "free riding"; kebutuhan mengunci likuiditas untuk stabilitas. (Inferensi)

Pressure: Kompetisi staking chain lain (Cardano, Tezos, PoS ETH menjelang merge) menaikkan standar insentif partisipasi. (Inferensi MEDIUM)

Trade-off: Holder kehilangan likuiditas 3 bulan per periode; sebagian memilih tidak berpartisipasi. (MEDIUM) [Ledger, https://www.ledger.com/staking-algorand]

Alternative(s) Considered: Mempertahankan participation rewards (ditolak — tidak mendukung governance); staking delegasi langsung (diadopsi kemudian 2025). (MEDIUM)

Expectation vs. Actual: Harapan: partisipasi voting tinggi + likuiditas terkendali. Actual: program berjalan 2021-2024 dengan partisipasi signifikan, lalu dihentikan 2025 digantikan consensus rewards. (MEDIUM) [99bitcoins-staking]
