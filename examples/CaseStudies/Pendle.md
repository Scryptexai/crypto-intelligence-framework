## Technology Intelligence
_ref: `docs/Ontology/Technology.md`_

System Architecture: AMM khusus yang memecah aset yield-bearing menjadi Principal Token (PT, klaim atas principal pada expiry) dan Yield Token (YT, klaim atas yield mengalir); V2 memperkenalkan arsitektur scalable dengan expiry fleksibel & boosted liquidity.
Core Components: PT/YT wrapper, Pendle AMM, oracle yield, sPENDLE staking, Boros funding-rate engine (Chainlink oracles), Citadels institusi (KYC).
Consensus Mechanism: Tidak applicable — protokol di atas chain host (Ethereum/Arbitrum/dll.).
Security Model: Audit multi-firma (Ackee, Dedaub) + competitive audits (Code4rena); track record sejak 2021; satu insiden hot wallet ~$1.7M (2024) tanpa kerugian dana pengguna.
Technical Upgrade History: Benchmark (2020) → V1 (2021) → V2 (Nov 2022) → Boros (Agu 2025) → sPENDLE (Jan 2026) + inflasi 2% (Mei 2026).
Known Technical Limitations: Ketergantungan pada keamanan aset underlying (LST/LRT) — risiko korelasi (YT memperbesar eksposur); risiko oracle funding-rate pada Boros.
