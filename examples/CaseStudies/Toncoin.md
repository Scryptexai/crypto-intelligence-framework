## Technology Intelligence
_ref: `docs/Ontology/Technology.md`_

System Architecture: "Blockchain of blockchains" tiga lapis — Masterchain (koordinasi global: config, validator set, referensi blok terbaru), Workchains (aturan khusus per chain; teori hingga 2^32 workchain), Shardchains (partisi state paralel; teori hingga 2^60 shard per workchain, split/merge dinamis).
Core Components: TVM (TON Virtual Machine) dengan bahasa FunC & Fift; struktur data cell/Bag-of-Cells; TON DNS, TON Sites, TON Storage, TON Payments; @wallet & Telegram Mini Apps SDK.
Consensus Mechanism: Proof-of-Stake dengan Catchain BFT (protokol Catchain tingkat rendah + Block Consensus Protocol); upgrade Catchain 2.0 (April 2026): block time ~2.5 detik → ~400 ms, finalitas <1 detik.
Security Model: Set validator terpilih berdasar stake; peran Validator/Nominator/Collator; minimum stake validator dilaporkan ratusan ribu TON (DACM mid-2023: 311 validator, min ~600 ribu TON); Nakamoto coefficient dilaporkan 2 per Agustus 2026 (kritik sentralisasi).
Known Technical Limitations: Eksekusi asinkron antar-shard memaksa developer menangani urutan pesan, eksekusi tertunda & kegagalan antar-kontrak; airdrop mega-scale (DOGS/HMSTR) memicu outage multi-jam Agustus 2024; ketergantungan strategis pada Telegram.
