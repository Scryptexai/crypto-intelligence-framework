## Security Model

Secure Element (Hardware Root of Trust): Setiap Hotspot bersertifikat wajib memasang ATECC608B (Microchip) atau TEE setara — menyimpan private key identity (Ed25519) tidak diekspor, menandatangani assert lokasi (GPS signed) dan coverage (beacon/witness), mencegah kloning perangkat dan spoofing lokasi (HIGH) [Helium Docs Hardware Security, https://docs.helium.com/mine-htn/security/; Kudelski Case Study, https://www.kudelskisecurity.com/case-studies/helium/]

Proof-of-Coverage Verification (Oracle Network): Jaringan oracle off-chain memverifikasi assert coverage secara kriptografis — memvalidasi RSSI/SNR konsisten dengan model propagasi RF, timestamp beacon/witness, dan konsistensi GPS; bukti diverifikasi dikirim ke program Solana untuk reward (HIGH) [Helium Docs PoC, https://docs.helium.com/tokens/proof-of-coverage/; HIP 70 Oracle Design, https://github.com/helium/HIP/blob/main/0070-migration-to-solana.md#oracles]

Solana Validator Set (Economic Security): Pasca-migrasi, keamanan state Helium (balance, staking, program logic) diamankan oleh validator Solana (ribuan node, >$B stake) via PoH/PoS — Helium tidak menjalankan validator sendiri (HIGH) [Solana Consensus, https://solana.com/docs/consensus; HIP 70 Migration, https://github.com/helium/HIP/blob/main/0070-migration-to-solana.md]

Program Security (Anchor + Audits): Semua program on-chain menggunakan Anchor (account validation, signer checks, CPI safety), diuji unit/integration (anchor test), dan diaudit oleh Trail of Bits (migrasi Solana) serta Kudelski (hardware/firmware) (HIGH) [Anchor Security, https://anchor-lang.com/docs/security; Trail of Bits Audit, https://github.com/trailofbits/publications/tree/master/reviews/helium; Kudelski Audit, https://www.kudelskisecurity.com/case-studies/helium/]

Threshold Signing / Multisig (Treasury & Upgrade Authority): Treasury SubDAO (IoT, Mobile) dan program upgrade authority dikendalikan via SPL Governance (Realms) dengan threshold multisig (mis. 3/5 atau 4/7 signer komunitas + core team) — tidak ada single key yang bisa memindahkan dana atau upgrade program (HIGH) [Realms Governance, https://realms.today/; Helium DAO Dashboard, https://dao.helium.com/; HIP 51/52 Treasury, https://github.com/helium/HIP/blob/main/0051-subdaos.md]

Denylist / Anti-Gaming Mechanism: Program on-chain memelihara denylist Hotspot yang terdeteksi gaming (spoofing lokasi, collusion witness, hardware tampering) — oracle mengflag, governance menyetujui penambahan, reward dihentikan (HIGH) [Helium Docs Denylist, https://docs.helium.com/tokens/denylist/; GitHub Denylist Issues, https://github.com/helium/denylist/issues]

## Governance

Governance Model: Multi-layer — Off-chain signaling (GitHub HIP Discussion, Discord, Forum) → On-chain voting (SPL Governance / Realms) menggunakan staked HNT/IOT/MOBILE voting power
Voting System: Token-weighted voting (1 staked token = 1 vote power) via SPL Governance program (Realms frontend); proposal tipe: parameter change, program upgrade, treasury spending, HIP ratifikasi

Treasury Governance: SubDAO Treasury (IoT & Mobile) dikendalikan on-chain via SPL Governance — proposal spending butuh quorum & threshold voto token staked SubDAO; Helium Foundation treasury off-chain (501(c)(3) board discretion)

## Inflation / Deflation

Inflation Mechanism: Proof-of-Coverage Emission — HNT diekspor per epoch ke Hotspot IoT operator (kurva emisi 2-year halving, mulai 5M HNT/bulan genesis); IOT & MOBILE diekspor per epoch ke Hotspot/Gateway operator SubDAO masing-masing (persentase dari emisi HNT induk + parameter SubDAO)

Burn Mechanism: Burn-and-Mint Equilibrium (BME) — HNT/IOT/MOBILE dibakar (burn) untuk mint Data Credits (DC); 1 DC = $0.00001 USD; DC digunakan untuk transfer data, onboarding Hotspot, operasi jaringan; burn mengurangi supply beredar
Buyback: Tidak ada program buyback protokol (tidak ada mekanisme otomatis membeli token dari pasar)
Supply Reduction: Net deflationary saat DC burn volume > emisi PoC per epoch (Burn-and-Mint Equilibrium design); saat ini emisi masih > burn (net inflationary) tapi trending menuju equilibrium
Status: Live
